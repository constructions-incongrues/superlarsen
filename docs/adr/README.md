# Les questions d'une radio associative

Monter et faire durer une radio associative pose toujours les mêmes questions :
où héberger les podcasts, comment tenir l'antenne la nuit, qui garde les accès
quand un bénévole s'en va. Voici celles que Super Larsen s'est posées, avec
nos réponses quand nous en avons.

Chaque question est une fiche de décision (un ADR). Elle dit le contexte, ce
que nous avons choisi et pourquoi, ce que ça nous coûte, et dans quel cas une
autre radio ferait mieux de répondre autrement. Nos réponses ne sont pas les
seules bonnes.

## Deux statuts

- **Proposé** : Super Larsen a tranché. La fiche attend la validation du
  collectif. Une section « Ce que nous ne savons pas » signale ce qui reste
  ouvert.
- **Question ouverte** : nous n'avons pas de réponse écrite. La fiche dit ce
  que nous ne savons pas, et garde une place pour les réponses d'autres radios.
